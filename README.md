# Night FM - 在线音乐播放器 🎧

一个基于网易云音乐的在线播放器，支持搜索、分类浏览、用户收藏、后台管理。

## 功能

- 💿 本地音乐播放（5 首原创 demo）
- 🌐 网易云音乐在线搜索播放
- 🔍 音乐分类浏览（华语、欧美、日语等 12 个分类）
- ❤️ 用户注册/登录 + 歌曲收藏
- 📊 后台管理（查看用户统计）
- 🎵 实时歌词滚动
- 📱 响应式设计（手机/电脑都能用）

## 环境要求

- **Node.js** >= 18（https://nodejs.org 下载安装）

## 快速启动

### 1. 安装依赖

```bash
cd ncm-api
npm install
```

### 2. 启动服务

```bash
node server.js
```

### 3. 打开浏览器

访问：**http://localhost:3000**

## 使用说明

### 首页播放器
- 左侧：封面、歌名、歌词
- 右侧：本地曲库 / 网易云搜索切换
- 底部：迷你播放控制栏（切歌后始终可见）

### 发现音乐
- 点击顶部「发现」→ 选择音乐分类 → 点击歌单 → 点击歌曲播放
- 歌曲旁边的 ♡ 可以收藏

### 收藏功能
- 需要先注册/登录账号
- 搜索或发现中听到喜欢的歌，点 ♡ 收藏
- 在「收藏」页面查看和管理

### 后台管理
- 使用 admin 账号登录后可见「后台」入口
- 查看注册用户数和收藏统计

| 层面 | 技术 |
|------|------|
| 前端 | 原生 HTML/CSS/JS |
| 后端 | Express (Node.js) |

## 常见问题

**Q: 为什么有些歌只有几十秒？**
A: 网易云 VIP 歌曲未登录只能试听。带「免费」标签的歌曲可以完整播放。登录网易云账号可获得更好体验。

**Q: 数据库在哪？**
A: `ncm-api/data.db`，SQLite 文件，可以直接复制备份。

**Q: 怎么换端口？**
A: 修改 `ncm-api/server.js` 最后一行 `const PORT = 3000` 改成其他数字。
